## 2024-05-24 - Avoid Event Loop Blocking & OOM with Sequential Async File Operations
**Learning:** When batch processing multiple large files (like images for PDF compilation), synchronous file reads (`fs.readFileSync`) block the Node.js event loop, severely degrading concurrent request performance. However, eagerly firing concurrent asynchronous operations (e.g., using `Promise.all()` with `fs.promises.readFile`) can cause massive memory spikes and Out of Memory (OOM) errors, as all file contents are loaded into RAM simultaneously.
**Action:** For batch processing large files, use sequential asynchronous operations (e.g., `await fs.promises.readFile` inside a `for...of` loop). This ensures the event loop is unblocked for other requests while strictly controlling memory utilization.
