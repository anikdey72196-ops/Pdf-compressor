## 2026-06-28 - Avoid Event Loop Blocking in Batch Processing
**Learning:** In Node.js, using synchronous file operations like `fs.readFileSync` or `fs.writeFileSync` in request handlers can block the main event loop, causing requests to hang and performance to degrade. While we want to process batch operations (like image compilation) sequentially rather than concurrently (with `Promise.all()`) to avoid massive memory spikes (OOM), we should still use *asynchronous* operations like `await fs.promises.readFile()` to yield control back to the event loop during I/O wait times.
**Action:** Always favor asynchronous I/O (`fs.promises` over `fs`) for file interactions in Express routes, especially when dealing with large files or batch operations. When iterating through a batch of files, use a standard `for...of` loop with `await` to process them sequentially.
